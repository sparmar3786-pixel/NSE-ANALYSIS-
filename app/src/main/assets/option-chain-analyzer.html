V10 engine
Uses 8/13 EMA and WaveTrend (Channel 10 / Average 21 / OB +60/+53 / OS −60/−53), plus option premium/OI flow, OI walls, volume and liquidity. Four-state classification: Long Buildup, Short Covering, Short Buildup, Long Unwinding. Snapshot-to-snapshot OI/premium change is preferred when timestamped history exists; exchange daily CHNG IN OI is the fallback.

Entry rule: buy CE only for a bullish setup and buy PE only for a bearish setup. Mixed daily OI vs short-term flow/trend is blocked rather than forced into a trade.

Exit rule: T1, T2, premium SL, underlying invalidation, trend/flow reversal, or selected timeframe time-stop. T1 is constrained to the configured 10–30 point range by default.

Signal: Long Buildup = ΔOI > 0 AND option Δprice > 0; Short Covering = ΔOI < 0 AND option Δprice > 0.
Setup score: 25 signal + 20 price momentum + 15 ΔOI strength + 15 volume percentile + 10 ATM proximity + 10 liquidity + 5 PCR/chain alignment.
Entry: controlled by Entry strike mode. ATM strike only restricts signals to the nearest strike to spot; Manual strike restricts signals to the nearest available strike to the entered value; Auto selects the best-scored eligible strike. Entry price: max(BID, min(LTP, ASK)) when quotes exist; otherwise LTP.
Delta proxy: |CE(K−step) − CE(K+step)| / (2×step) for CE, analogous PE. Underlying targets use the next OI wall; option target ≈ Entry + Δ × (TargetUnderlying − Spot) for bullish plans.
SL: the tighter of premium-% stop and chain invalidation estimate, with a floor to avoid zero/negative premium. Target 2 uses R:R. Exit = Target/SL hit, signal invalidation, or the selected timeframe time-stop. Backtest uses future uploaded snapshots only; entry uses ASK when available and exits use BID when available. Spike detector: premium velocity + volume burst + OI confirmation; it requires timestamped consecutive snapshots and does not claim a statistical probability from one snapshot.

6) Historical backtest — real uploaded snapshots only

Entry strike control: The backtest uses the same selected Entry strike mode as the live planner. Select ATM strike only to backtest only the nearest ATM CE/PE at each snapshot, or Manual strike for a chosen strike.

Backtest integrity: 100 means 100 completed trades per tested timeframe, not repeated observations of the same signal. Signals are matched by INDEX + EXPIRY + STRIKE + CE/PE, and timeframe calculations require real snapshot timestamps. If timestamps are missing, the tool must not claim 1m/5m/15m performance.

No fake 100-trade result: this backtest only counts trades that can be reconstructed from multiple dated option-chain snapshots. One snapshot can generate signals, but it cannot prove whether SL/target was hit later. Upload 100+ historical NSE option-chain CSV snapshots (preferably same index/expiry and dated filenames). The engine will then generate signals, enter at the signal snapshot ASK when available, and walk forward through later snapshots for SL/Target. If fewer than 100 completed trades exist, it will show the actual count instead of inventing a 100-trade result.

Important probability note

A single option-chain snapshot cannot honestly prove a real 70% probability of profit. This tool therefore uses 70+ as a setup-score threshold, not a statistically calibrated win probability. A true 70% probability would require historical labelled trades/backtesting and out-of-sample calibration. The score is designed to combine OI, premium momentum, volume, liquidity, ATM proximity and OI-wall structure without claiming certainty.
